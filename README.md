# Nurse Scheduler Prototype

병동 간호사 근무표를 GitHub Pages에서 바로 열어볼 수 있게 만든 정적 HTML 프로토타입입니다.

## 목표
- 별도 서버 없이 GitHub Pages 배포
- 엑셀처럼 한 달 근무표 확인
- 사람별 월 목표 근무수(D/S/E/N/OFF) 직접 수정
- 사람별 리퀘스트(쉬고 싶은 날, 선호/회피 쉬프트) 입력
- 실제 표 이름 순서를 그대로 기본값으로 반영
- 사람별 특징 반영 가능 (예: 서민경 N전담, 월 N 14)
- 날짜별 부족/초과 배정 시 연한 경고색으로 즉시 표시

## 현재 기능
- 기본 샘플은 실제 표의 이름 순서/연차순 기준으로 세팅
- 사람별 규칙 편집표 제공
  - senior
  - main shift
  - canS
  - N전담
  - max consecutive N
  - AL quota
  - canN
- AN/지원 인력 별도 입력 제공
- 3교대 + S 포지션
- 요일별 필요 인원 자동 반영
  - 월/금: D3 E3 N2
  - 화/수/목: D2 + S1 / E2 / N2
  - 토: D3 E2 N2
  - 일/공휴일: D2 E2 N2
- 화/수/목의 주간은 `D2+S1` 조합을 정상으로 처리하며, D 1명이 S로 대체된 경우 경고 없음
- N은 매일 정확히 2명 기준으로 검사
- N은 기본적으로 2연속 블록을 기준으로 보되, 3연속 이상도 입력 가능하며 이 경우 규칙 경고 표시
- N 다음날은 OFF 필요
- 연속된 N 이후에는 OFF 2연속 필요
- E 다음날 D/S 금지
- S는 연차 하위 5명만 가능
- 기본적으로 1~6번을 고연차로 간주
- 모든 쉬프트에 가능하면 고연차 1명 포함
- 단, 주말/공휴일 E는 저연차만 2명이어도 허용
- 수간호사(1번) D만, 목/일 OFF
- 표에서 셀 직접 수정 가능
- 표에서 목표치 직접 수정 가능
- 리퀘스트 직접 수정 가능
- 커버리지 불일치 시 시각 경고
- 현재 상태 JSON 저장 가능

## 입력 형식
왼쪽의 인원 기본값 textarea는 아래 형식입니다.

```text
번호,이름,role,maxN,preferred,blocked,request
```

예시:

```text
1,1,HN,0,D,Thu|Sun,prefer:D:1|2|4
7,7,RN,6,N,,off:10|11;avoid:E:12|13
```

### 필드 설명
- `번호`: 연차순 번호
- `이름`: 화면 표시 이름
- `role`: `HN` 또는 `RN`
- `maxN`: 월 N 목표/상한 기본값
- `preferred`: 기본 선호 쉬프트 (`D`,`S`,`E`,`N`)
- `blocked`: 요일 고정 OFF (`Thu|Sun` 같은 형식)
- `request`: 개별 요청

## request 문법
세미콜론(`;`)으로 여러 요청을 나눕니다.

### 1) 특정 날짜 OFF 요청
```text
off:5|12|26
```

### 2) 특정 쉬프트 선호
```text
prefer:D:1|2|3
prefer:N:14|15
```

### 3) 특정 쉬프트 회피
```text
avoid:E:20|21
avoid:N:28|29
```

조합 예시:

```text
off:5|12;prefer:D:1|2|3;avoid:N:20|21
```

## GitHub Pages 배포 방법

### 방법 1: 새 저장소에 바로 올리기
1. GitHub에서 새 저장소 생성
2. 이 폴더의 `index.html`과 `README.md` 업로드
3. 저장소 설정(Settings) → Pages
4. Source를 `Deploy from a branch`로 선택
5. Branch를 `main` / root 로 선택
6. 저장하면 Pages URL 생성

### 방법 2: 로컬에서 git으로 올리기
```bash
git init
git add .
git commit -m "init nurse scheduler prototype"
git branch -M main
git remote add origin <YOUR_REPO_URL>
git push -u origin main
```
그 뒤 GitHub Pages를 켭니다.

## 사용 흐름
1. 연도/월/공휴일 입력
2. 인원 기본값 + 지원/AN 인력 입력 또는 샘플 불러오기
3. 표 생성 / 다시 계산 클릭
4. 사람별 규칙 편집표에서 profile 수정
5. 생성된 표에서
   - 셀 직접 수정
   - 월 목표치 수정
   - 리퀘스트 수정
6. 부족/초과가 생기면 하이라이트 확인
7. JSON 저장으로 현재 설정 백업

## 추가 레퍼런스(실제 2026년 2월 표)에서 읽힌 완화/추가 원칙

실제 참고표를 보면 현재 프로토타입보다 더 유연하게 운영됩니다. 반영 또는 검토할 요소:

- `연`은 OFF와 동일한 휴무이지만, 추가 연차를 사용한 OFF로 별도 집계
- AN(액팅/지원) 행이 별도로 존재하며 `S`, `H`, `반`, `연` 같은 코드로 운용됨
- N 전담 인력(예: 서민경)은 월 N이 크게 높고 다른 쉬프트는 거의 없음
- 일부 인원은 D/E/N보다 S 비중이 높음
- 고연차 1명 원칙은 강제보다 우선배치에 가까움
- 실제 표는 3연속 N 또는 강한 편중도 일부 허용하고, 대신 휴무/연차로 보정함
- 주간은 `D`와 `S`를 묶어서 커버하는 날이 많아 `D 단독 충족`보다 `주간 총량 충족`이 더 중요함
- 개인별 전담 패턴이 강함: D 위주, E 위주, N 전담, S 전담/보조 등
- 추가 지원 인력(AN)을 별도 풀로 두면 본 병동 11명 규칙을 덜 깨고도 커버 가능
