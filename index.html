기본 설정

규칙

고정 규칙: E 다음날 D/S 금지 · 수간호사(1번)는 D만 가능, 목/일 OFF · 1~6번을 고연차로 간주

인원 기본값

형식: 번호,이름,role,maxN,preferred,blocked,request
request 예시: off:5|12;prefer:D:1|2|3;avoid:N:18|19
참고표 기반 추가 해석: 사람별 전담패턴(D/E/N/S), 추가 연차OFF(연), AN/지원행 분리 가능

참고 원칙

- 월/금: D3 E3 N2
- 화/수/목: D2 + S1 / E2 / N2
- 토: D3 E2 N2
- 일/공휴일: D2 E2 N2
- 모든 쉬프트에 가능하면 고연차 1명 포함(기본: 1~6번)
- 단, 주말 E는 저연차 2명만 배정돼도 허용
- `연`은 추가 연차 OFF로 보고 별도 집계 가능
- 실제 참고표 기준: D와 S는 주간 총량으로 유연하게 대체 가능
- 부족/초과 배정은 표와 커버리지에서 연하게 경고 표시

사람별 규칙 편집

생성 후 senior / main shift / canS / N전담 / 최대연속N / 연 quota / canN 수정 가능
